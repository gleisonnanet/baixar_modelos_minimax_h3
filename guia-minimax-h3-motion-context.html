Visão geral

Este workflow cria vídeos longos com o MiniMax H3 encadeando trechos. Cada trecho continua do anterior usando o contexto salvo, e o resultado é um plano contínuo, sem cortes.

Sem limite fixo de duração.O workflow de exemplo vem com 3 trechos de 8 segundos (24 s), mas você pode adicionar quantos trechos quiser na timeline do editor e fazer o vídeo durar o tempo que precisar. Na prática, o limite é o seu tempo de geração e o espaço em disco.

02

Programas no Windows

Instale na ordem. O ComfyUI foi ensinado em outro vídeo (veja o Passo 03), mas o Git e o FFmpeg não, então instale os dois aqui.

Instalar o FFmpeg (PowerShell)

winget install Gyan.FFmpeg

Feche e abra o PowerShell e confira:

ffmpeg -version

Sem o winget, baixe o FFmpeg em gyan.dev/ffmpeg/builds e adicione a pasta bin ao PATH do Windows.

04

Custom nodes, sem Manager

Este workflow usa dois pacotes. O núcleo do ComfyUI cobre o resto.

PacoteNós usadosLink
ComfyUI-Easy-Mediaeasy multiTrackEditor, easy multitrackProject, easy multitrackProjectVideoCombine, easy modelLoaderPack, easy saveVideoGitHub
ComfyUI-KJNodesModelPreviewOverrideKJ, MiniMaxH3MemoryEfficientSageAttentionPatchGitHub

1. Confira o caminho do ComfyUI

Os comandos abaixo usam o caminho que você digitou no Passo 03. Se ainda não digitou, volte lá primeiro. Não precisa entrar na pasta custom_nodes. Rode este teste antes de clonar:

Test-Path "{ROOT}\ComfyUI\custom_nodes"
Tem que aparecer True.Se aparecer False, o caminho do Passo 03 está errado. Não clone ainda: o git cria as pastas mesmo no lugar errado, sem dar erro, e os nós não aparecem no ComfyUI.

2. Clone os dois pacotes

git clone https://github.com/yolain/ComfyUI-Easy-Media.git "{ROOT}\ComfyUI\custom_nodes\comfyui-easy-media"
git clone https://github.com/kijai/ComfyUI-KJNodes.git "{ROOT}\ComfyUI\custom_nodes\ComfyUI-KJNodes"
Mantenha o nome da pasta comfyui-easy-media.Não deixe duas cópias do Easy-Media dentro de custom_nodes. Se aparecer o erro already exists and is not an empty directory, você já tem essa pasta (por exemplo, instalada antes pelo Manager): use a caixa "X vermelho" logo abaixo. Se aparecer git não é reconhecido, instale o Git (Passo 02) e abra um PowerShell novo.

3. Instale as dependências do KJNodes

O git clone não instala dependências sozinho (o Manager faria isso). Rode:

& "{ROOT}\python_embeded\python.exe" -m pip install -r "{ROOT}\ComfyUI\custom_nodes\ComfyUI-KJNodes\requirements.txt"

O Easy-Media não tem arquivo de dependências, então não precisa deste passo para ele.

4. Reinicie o ComfyUI

Feche o ComfyUI por completo e abra de novo. Para atualizar um pacote no futuro:

git -C "{ROOT}\ComfyUI\custom_nodes\comfyui-easy-media" pull
git -C "{ROOT}\ComfyUI\custom_nodes\ComfyUI-KJNodes" pull
Os nós do Easy-Media aparecem com X vermelho? (instalou pelo Manager antes)

Quem instalou o Easy-Media pelo Manager pode ficar com a versão 1.2.1. Essa pasta não é um repositório git (não atualiza com git pull) e não tem os nós easy multitrackProject, easy multitrackProjectVideoCombine e easy modelLoaderPack. Eles aparecem em vermelho, com campos "UNKNOWN". O editor carrega normalmente, o que confunde.

A solução que funcionou: trocar a pasta por um clone git da versão atual (1.3.4). Feche o ComfyUI e rode:

New-Item -ItemType Directory -Force "{ROOT}\ComfyUI\custom_nodes_backup" | Out-Null
Move-Item "{ROOT}\ComfyUI\custom_nodes\comfyui-easy-media" "{ROOT}\ComfyUI\custom_nodes_backup\comfyui-easy-media-antigo"
git clone https://github.com/yolain/ComfyUI-Easy-Media.git "{ROOT}\ComfyUI\custom_nodes\comfyui-easy-media"

O backup vai para fora de custom_nodes, para o ComfyUI não carregar as duas cópias. Depois abra o ComfyUI e use Ctrl+F5 no navegador.

Opcional: NativeAudioLock (só para vídeos com fala)

Não é necessário para este workflow. O nó de áudio travado fica desativado quando o vídeo não tem fala. Ele está dentro de outro repositório, então clone numa pasta temporária e copie só a pasta do nó:

Set-Location "{ROOT}\ComfyUI\custom_nodes"; git clone https://github.com/Shrek3OnVH5/MiniMax-H3-NativeAudio-MusicVideo-Workflow.git _h3tmp; Copy-Item -Recurse "_h3tmp\custom_nodes\ComfyUI-H3-NativeAudioLock" .; Remove-Item -Recurse -Force _h3tmp
Não instale o ComfyUI-MiniMaxH3-Cache.A página do ComfyUI Wiki avisa que ele pode quebrar a geração do H3. Se já instalou, apague a pasta dele e reinicie.
05

SageAttention e Triton (NVIDIA)

É o passo mais chato do Windows.O nó MiniMaxH3MemoryEfficientSageAttentionPatch, do KJNodes, precisa do SageAttention, que por sua vez precisa do Triton. Sem eles o nó dá erro. Se não conseguir instalar, siga para o fim deste passo.
  1. Instale o Visual C++ Redistributable (Passo 02, item 4), se ainda não instalou.
  2. Copie as pastas include e libs do Python para dentro de python_embeded. O ComfyUI portátil atual usa Python 3.13, e o repositório do triton-windows disponibiliza o arquivo certo para cada versão. Use libs (não mexa na pasta Lib). Repositório do triton-windows
  3. Veja a sua versão do PyTorch e do CUDA: 
    & "{ROOT}\python_embeded\python.exe" -c "import torch; print(torch.__version__, torch.version.cuda)"
  4. Instale o Triton para Windows. A versão do triton-windows precisa casar com a do PyTorch. No PC do autor, com o ComfyUI portátil atual (PyTorch 2.13 e CUDA 13), funciona exatamente esta versão, por isso o comando a fixa: 
    & "{ROOT}\python_embeded\python.exe" -m pip install "triton-windows==3.7.1.post27"
    Se o resultado do comando anterior mostrar outro PyTorch, confira a tabela de versões no repositório do triton-windows. Evite pip install -U triton-windows: ele instala sempre a versão mais nova, que pode não casar com o seu PyTorch.
  5. Baixe a roda (arquivo .whl) do SageAttention que combine com o seu CUDA (cu128 ou cu130) e com o PyTorch, nas releases do projeto. No PC do autor está o SageAttention 2.2.0 para cu130. Coloque o arquivo .whl dentro da pasta ComfyUI_windows_portable (a mesma que você digitou no Passo 03) e rode o comando, que acha o arquivo sozinho: 
    & "{ROOT}\python_embeded\python.exe" -m pip install (Get-ChildItem "{ROOT}\sageattention*.whl").FullName
    Deixe só um arquivo sageattention...whl nessa pasta.
    Releases do SageAttention para Windows
  6. Teste: 
    & "{ROOT}\python_embeded\python.exe" -c "import triton, sageattention; print('ok')"
Não conseguiu?Tente desativar o nó de SageAttention no workflow (selecione e aperte Ctrl+B). O autor do workflow deixou uma alternativa desativada (ModelAttentionBackend, "comfy kitchen attention"). Não testei o workflow sem o SageAttention.

07

Abrir e configurar o workflow

MINIMAX H3 Motion Context V2
Arquivo .json do workflow (abre o Google Drive em outra aba)
Baixar workflow
  1. Arraste o arquivo .json para dentro do ComfyUI. Nenhum nó deve aparecer em vermelho.
  2. Escolha os arquivos nas listas (os nomes devem aparecer, porque você baixou na pasta certa):
    • UNETLoader: o modelo Singularity que você baixou (podado ou de 34 GB).
    • CLIPLoader: qwen3vl_32b_minimax_h3_int8_convrot (já vem selecionado no workflow), tipo minimax. Se baixou o nvfp4 mais leve, escolha ele na lista.
    • VAELoader (2x): o VAE de vídeo e o VAE de áudio.
    • LoraLoaderModelOnly: o LoRA turbo de 4 passos, força 1.0.
    • easy multitrackProject, campo do upscaler: escolha o arquivo de upscaler que você baixou. O workflow procura minimax_h3_latent_upscaler_3d_bf16. Se você não renomeou o arquivo (Passo 06), o nome não estará na lista e o ComfyUI barra a execução até você escolher o seu.
  3. Imagem de referência: no editor multitrilha, no trecho 1, adicione a imagem da sua personagem. Passe o mouse sobre ela, clique no ícone de compartilhar e escolha "Use as shared reference". Os trechos seguintes herdam a imagem.
  4. Nome do projeto: preencha o project_name (vazio vira "default").
  5. Teste curto primeiro: coloque segment_count em 1 para gerar só o primeiro trecho. Funcionando, volte para -1 (todos os trechos).
  6. Quer um vídeo mais longo? Adicione mais trechos na timeline do editor. O trecho 1 é o "shot" e todos os seguintes são "context" (continuam do anterior). Escreva um prompt de continuação para cada um e gere de novo.

Receitas embutidas no workflow

Passos (nó verde)
  • 8: padrão (dança, mãos rápidas, fundo cheio, andar e falar)
  • 6: pouco movimento (rosto falando, câmera parada)
  • 4: só sem fala, senão perde sílabas
Resolução
  • 1,0 MP: padrão rápido para testar
  • 1,4 MP: até cerca de 10 s por trecho em placa de 24 a 32 GB
  • Regra de VRAM: quadros x megapixels no máximo cerca de 540 por trecho
Dicas de prompt para trechos de continuação
  • Abra cada trecho de contexto só com a continuação: mesmo ritmo, mesma câmera, mesma luz, e nenhum substantivo de cenário.
  • Os tempos de um trecho de contexto caem cerca de 0,92 s antes no vídeo final. Escreva T + 0,92 para cair em T.
  • Nunca carregue um movimento de câmera progressivo através de uma emenda. Coloque as emendas no meio de uma caminhada ou corrida, nunca numa porta.
  • Diálogo: cerca de uma frase curta a cada 2,5 s.
  • Não quer escrever os prompts do zero? Use o System Prompt do Passo 08: um agente de IA planeja os trechos e entrega um prompt pronto para cada um.
Onde ficam os vídeos:ComfyUI\output\easy_media\projects\NOME_DO_PROJETO\. Para refazer só um trecho, use segment_start_number = N e segment_count = 1. A continuação precisa do contexto salvo nessa pasta, não basta o MP4.
08

Prompts prontos com um agente

Você não precisa criar os prompts do zero. O System Prompt abaixo transforma um agente de IA (ChatGPT, Claude, Gemini ou outro) num escritor de prompts para este workflow: você conta a história e ele planeja os trechos, diz como configurar o editor e entrega um prompt pronto para colar em cada trecho.

MiniMax H3 Long Take (Motion Context) Prompt Writer
Arquivo de texto com as instruções do agente (abre o Google Drive em outra aba)
Baixar System Prompt

O que o agente faz

  • Pergunta só o que faltar: a história, a duração total, a proporção (16:9 ou 9:16), os personagens e as falas.
  • Escolhe o tamanho e a resolução dos trechos e mostra um plano de trechos para você aprovar.
  • Explica como configurar o editor multitrilha (resolução, trecho 1 como "shot" e os seguintes como "context", imagem de referência só no trecho 1).
  • Entrega um prompt por trecho, no formato que o workflow usa, já com o bloco de continuação nos trechos de contexto e os tempos ajustados.

Como usar, passo a passo

  1. Baixe o arquivo pelo botão acima e abra no Bloco de Notas.
  2. Copie todo o texto (Ctrl+A e depois Ctrl+C).
  3. Cole como instrução do agente. O melhor é colocar na área de instruções fixas, para valer em todas as conversas. O nome muda conforme o app: nos Projetos do Claude e do ChatGPT é o campo de instruções do projeto; num GPT personalizado ou num Gem do Gemini é o campo "Instruções". Se o seu app não tiver isso, cole como a primeira mensagem de uma conversa nova.
  4. Mande a sua ideia. Exemplo de mensagem (adapte à sua história): 
    História: uma mulher acorda num porão escuro, pega uma lanterna, encontra uma escada e sobe até o convés de um navio, de noite.
Duração total: 45 segundos.
Proporção: 16:9.
Personagem: uma mulher, vou enviar uma foto de referência dela.
Falas: nenhuma.
  5. Confira o plano de trechos que o agente mostrar e peça ajustes antes de seguir.
  6. Copie cada prompt (um por trecho) e cole no trecho correspondente do editor multitrilha, na ordem. A imagem de referência vai só no trecho 1, como referência compartilhada (Passo 07).
Os prompts saem em inglês.É o idioma que o workflow espera. Se tiver falas, elas também ficam em inglês, segundo as regras do System Prompt.
Revise antes de gerar.O agente é uma IA e pode errar. Confira o plano de trechos e leia cada prompt antes de colar. Este System Prompt foi escrito para o editor multitrilha deste workflow, e não serve para outros fluxos.
09

Problemas comuns

Nós em vermelho (easy multitrackProject, VideoCombine, modelLoaderPack)

É o Easy-Media antigo (1.2.1). Veja o quadro "X vermelho" no Passo 04 e troque pela versão git.

"Value not in list" no campo do upscaler

O nome salvo no workflow não existe na sua pasta. Abra o nó easy multitrackProject e escolha, na lista, o arquivo de upscaler que você baixou, ou renomeie o arquivo (Passo 06). O mesmo vale para o CLIPLoader se você baixou outro codificador de texto.

Erro de SageAttention ou Triton

Confira se o Triton e o SageAttention combinam com a sua versão do PyTorch e do CUDA (Passo 05). Se não resolver, desative o nó de SageAttention com Ctrl+B.

FFmpeg não encontrado

Rode ffmpeg -version num PowerShell novo. Se der erro, o FFmpeg não está no PATH. Feche o ComfyUI e abra de novo depois de corrigir.

Sem memória (OOM) ou travando o PC
  • Baixe a resolução para 1,0 MP.
  • Gere um trecho por vez (segment_count = 1).
  • Use o modelo podado (21 GB) e não o de 34 GB.
  • Feche navegador e outros programas pesados. Com 32 GB de RAM o Windows pode usar o disco como memória, e fica lento.
O editor multitrilha quebra depois de atualizar o ComfyUI (frontend 1.53 ou mais novo)

Um aviso do autor do workflow descreve esse caso: o MultiTrack Editor perde a entrada de megapixels e abre workflows antigos com a timeline vazia. A causa seria um conflito com o pacote ComfyUI-Easy-Use.

  • Se você não tem o Easy-Use instalado, isso não se aplica. No PC do autor não há Easy-Use, e o editor funciona no frontend 1.55.
  • Se tiver o Easy-Use e o problema aparecer: não aperte o botão "Fix" do nó, e não salve um workflow que foi aberto com o erro, porque a timeline pode ter sido sobrescrita.
  • Reinstalar ou voltar a versão do Easy-Media não resolve, segundo o aviso.
AMD: erro ao carregar o VAE

Há um relato de falha no Windows com RX 9070 XT. Veja o quadro AMD no Passo 01.
